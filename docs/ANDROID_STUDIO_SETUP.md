# Android Studio setup steps

## Requirements
- Android Studio latest stable
- JDK 17
- Android SDK 34 or above

## Steps
1. Open the repository in Android Studio.
2. Wait for Gradle sync.
3. Build the project.
4. Select a device or emulator.
5. Run the app.

## Notes
- The project is structured as a Compose app with navigation and document-related screens.
- Replace placeholder backend calls with real API endpoints when ready.
- Add file permissions for devices running Android 13 and below as needed.
