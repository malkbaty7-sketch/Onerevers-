# KaatibDocsPro: Roadmap

## Phase 1: App foundation
- Compose app shell
- navigation stack
- document list and settings
- home dashboard

## Phase 2: PDF and document tools
- PDF merge/split/compress
- document viewer and metadata display
- file selection and local storage support

## Phase 3: Extraction engine
- Tika server or SDK integration
- extracted text display
- metadata extraction and formatting

## Phase 4: Conversion engine
- PDF to Word backend service
- conversion job states
- download and preview of converted docs

## Phase 5: Polish and deploy
- Arabic localization
- professional UI design
- permission handling and store support
- testing and deployment
