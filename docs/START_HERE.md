# Start Here

## Step 1: Open the project
Open this repository in Android Studio.

## Step 2: Sync Gradle
Allow Gradle to resolve dependencies.

## Step 3: Run the app
Select an emulator or a physical device.

## Step 4: Use the app shell
The app currently includes:
- home screen
- document list
- PDF tools
- extraction screen
- conversion flow

## Step 5: Start backend services
Run the Python services in the backend folder.

## Step 6: Connect real APIs
Replace the placeholder endpoints with your real production services.

## Step 7: Add production logic
Integrate:
- ClearPDF components
- Tika extraction service
- PDF2Word conversion pipeline
- secure storage and document operations
